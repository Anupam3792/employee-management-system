# Employee Management System

## 📌 Project Overview

Employee Management System is a web-based application developed using Java Spring MVC framework. It provides an efficient way to manage employee records with secure admin authentication and complete CRUD operations.

## 🚀 Features

* Admin Login & Logout
* Add Employee
* Update Employee Details
* Delete Employee
* Search Employee by ID
* Display All Employees
* Session Management
* Dashboard Analytics
* Pagination Support
* Department-wise Filtering

## 🛠️ Tech Stack

* Java
* Spring MVC
* Hibernate
* MySQL
* JSP
* JSTL
* Maven
* Apache Tomcat

## 📂 Project Structure

* Controller Layer
* Service Layer
* Repository Layer
* Model Layer
* JSP Views

## 🗄️ Database

Database: MySQL

Tables:

* admin
* employees

## ⚙️ Installation Steps

1. Clone the repository
2. Import project into Eclipse
3. Configure MySQL database
4. Update database credentials
5. Run the project on Apache Tomcat server
